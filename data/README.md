# Synthetic HR datasets

Every record in this directory is fictional test data. It is intentionally marked with `synthetic_record=TRUE` and must not be treated as real employee information.

Files:

- `employee_profiles.csv`: fictional employee profiles, employment types, offices, and status.
- `pto_balances.csv`: fictional PTO and sick-leave balances.
- `benefits_elections.csv`: fictional benefits elections and contribution settings.
- `manager_relationships.csv`: fictional reporting relationships.
- `office_locations.csv`: fictional office and workplace locations.
- `hr_tickets.csv`: fictional HR support tickets.

All employee IDs use the `DEMO-` prefix, ticket IDs use the `TKT-DEMO-` prefix, and email addresses use the reserved `example.test` domain.
